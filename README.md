**Nobel Prize Portrait** 是一个轻松娱乐向的图像 Skill：上传照片，生成的“诺奖得主风格肖像”。

<a id="gallery"></a>

## 效果展示

两张输出示例，适合实验室群聊、毕业季头像、答辩封面和朋友圈玩梗。

| 输出示例 A | 输出示例 B |
| :---: | :---: |
| ![墨线与赭金色学者肖像示例 A](docs/images/output-example-a.png) | ![墨线与赭金色学者肖像示例 B](docs/images/output-example-b.png) |

示例图片由用户提供，仅用于展示风格。实际结果会受到人物照片、提示词和模型影响。

## 它能干什么

- 把硕士、博士、导师和同门画成“诺奖候选人”。
- 把熬夜、改论文、做实验的状态，变成一本正经的学者肖像。
- 保留本人特征，也可以把发型、表情和气质稍微夸张一点。
- 生成适合头像、实验室海报、毕业纪念和群聊整活的图片。

<a id="quick-start"></a>

## 怎么用

上传一张人物照片，然后输入：

```text
使用 $nobel-prize-portrait，把我画成刚拿诺奖、但还在改论文的博士生。
保留我的脸和主要特征，黑色墨线、少量赭金色、暖白纸张，表情自信又有一点疲惫。
```

也可以直接说：

```text
把导师画成实验室里的诺奖得主，发型和表情可以夸张一点，幽默但不要变成卡通人物。
```

## 玩梗提示词

### 博士生版

```text
把我画成刚获得诺贝尔奖的博士生，但看起来还没睡醒。
保留本人特征，头发可以乱一点，眼神要有“终于毕业了”的感觉。
使用黑色墨线、少量赭金色和暖白纸张，不要文字和水印。
```

### 导师版

```text
把这位老师画成实验室诺奖得主，气质自信、表情淡定，
像是已经知道这个结果会发在顶刊。保留人物特征，风格幽默但不要低俗。
```

### 同门版

```text
把我的同门画成诺奖得主，保留脸部特征，加入一点“实验终于成功”的得意表情。
头发、眉毛和姿势可以略微夸张，但整体仍然像一幅认真画的学者肖像。
```

### 更离谱一点

```text
把我画成刚拿诺奖、刚拒绝三个顶刊邀请、但晚上还要改实验记录的人。
允许更夸张的发型、表情和姿态，但保留基本辨识度。
黑色墨线、赭金色点缀、暖白纸张，不要真实诺贝尔标志。
```

## 默认风格

- 黑色手绘墨线，线条有粗有细。
- 暖白或象牙白纸张质感。
- 少量哑光赭金色，像“获奖滤镜”，但不做金光闪闪的海报。
- 保留人物基本辨识度，允许发型、表情和气质适度夸张。
- 可以有博士生的疲惫、导师的淡定、实验成功后的得意。
- 默认不添加文字、真实诺贝尔标志、姓名、奖章或水印，避免生成乱码。

## 安装

### 一键安装到 Codex

下载github压缩包发送给Codex即可

## 上传到 GitHub

如果你要把它放到 GitHub：

1. 解压 ZIP。
2. 创建一个空仓库。
3. 将 `nobel-prize-portrait/` 里面的内容上传到仓库根目录。
4. 确保 `README.md`、`SKILL.md`、`agents/`、`assets/` 和 `docs/` 在同一层级。

GitHub 的 **Import repository** 适合导入已有远程 Git 仓库地址，不能直接把本地 ZIP 自动解压成仓库。
