## 可复用提示词

### 基础指令

```text
使用 $nobel-prize-portrait，把这张人物照片转化为诺贝尔奖公告风格的艺术肖像。
使用温暖象牙白纸张、富有变化的黑色墨线和少量哑光赭金色。
保留人物主要面部特征，采用居中的竖版头肩构图，不添加文字、徽章、签名或水印。
```

### 更高人物保真度

```text
尽量保留人物的五官、发型、眼镜、年龄感和姿态。
让画面呈现真实手绘效果：减少皮肤纹理和连续渐变，保留大面积暖白留白，
用少量赭金色表现局部明暗，不要把结果处理成照片滤镜。
```

### 更强艺术表现

```text
保留人物基本辨识度，但允许适度调整脸部比例和发型。
让头发使用分离的黑色笔触，轮廓线更自由，衣服以简洁线稿表现，
额头、脸颊和外套保留大面积纸张留白，赭金色只做局部图形化点缀。
```

### 微笑与表情

```text
让人物带一点自然、克制的闭嘴微笑，嘴角轻轻上扬，眼神温和。
保持正式学者肖像的气质，不要露齿大笑、夸张表情或卡通化变形。
```

### 使用风格参考图

```text
第一张图片是需要绘制的人物，第二张图片只作为插画风格参考。
保留第一张图片的人物特征，参考第二张图片的线条、配色和留白。
不要复制风格参考图中的人物、文字、标志、签名或水印。
```
